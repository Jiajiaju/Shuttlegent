# 常见问题

本文按问题整理使用中常遇到的情况，给使用者看。各项设置的说明见 [Configuration.md](Configuration.md)。

## 1. 安装与连接

### 1.1 面板提示“还没有可用的模型连接”或“鉴权失败”

- **还没有可用的模型连接**：在 **编辑器偏好设置 > Shuttlegent > General > Models** 至少让一条连接显示 Connected：给内置 DeepSeek 连接填密钥，或添加一条连接填 Base Url 和 Api Key。
- **显示 Failed**：在 Output Log 里搜 `Connection test`，看是哪一步失败（地址不通、密钥被拒、没有模型列表）。
- **鉴权失败**：检查密钥是否填错、是否过期，以及 Base Url 和密钥是否属于同一个服务。

改完后在面板点“重试”。

### 1.2 面板提示找不到运行时

插件目录下缺少 `Runtime/shuttlegent-runtime.exe`，通常是插件包没有完整解压，或用的是 clone 下来的源码。从 [Releases](https://github.com/Jiajiaju/Shuttlegent/releases) 重新下载插件包解压覆盖；或者在 **编辑器偏好设置 > Shuttlegent > General > Runtime > Runtime Executable Override** 里指定一个已有的运行时。

### 1.3 改了模型设置没生效

模型连接和权限开关在运行时重启后才生效：在面板点“重试”，或重启编辑器。工具开关和 Toolset 开关立即生效。

### 1.4 能不能用其他模型

可以。在 **编辑器偏好设置 > Shuttlegent > General > Models** 添加一条连接，只填 Base Url（如 `https://api.openai.com/v1`）和 Api Key。插件自动识别协议（OpenAI Responses、OpenAI Chat Completions、Anthropic Messages，含兼容这些协议的团队网关、本地模型服务），并列出这个密钥能用的全部模型，都会出现在面板的模型菜单里。

新会话默认用第一条已连通的连接中的第一个模型；内置 DeepSeek 连接没填密钥时会被跳过。详见 [Configuration.md §1](Configuration.md#1-模型agent-与默认值个人)。

### 1.5 密钥存在哪里，会不会进版本库

密钥只保存在本机的 `Saved/Config/WindowsEditor/EditorPerProjectUserSettings.ini`，明文存放，不进版本库，也不会写进运行时的补丁文件。

### 1.6 Agent 说没有某个引擎 Toolset

依次检查三处：

1. 这个 Toolset 插件是否已在 **编辑 > 插件** 里启用，并已重启编辑器；
2. **项目设置 > Shuttlegent > General > Engine Toolsets > Blocked Toolset Names** 是否屏蔽了它；
3. **编辑器偏好设置 > Shuttlegent > General > Engine Toolsets** 里它的开关是否打开。

## 2. 改动与撤销

### 2.1 确认卡一直不出现，改动被拒绝

- 改动需要面板打开才能确认，面板关闭时改动请求会被直接拒绝；确认卡出现后 55 秒内没确认也视为放弃。保持面板打开，再让 Agent 重试。
- 看一下输入框下方的模式：**计划** 模式下所有改动都会被拒绝，Agent 要先交计划、你批准后才能动手。

### 2.2 改动能撤销吗

- 内置工具的改动在编辑器事务里执行，可以在对话里点“撤销”，也可以用 Ctrl+Z。
- 保存资产、新建资产、导出文件不能撤销，确认卡会标明。
- 引擎 Toolset 工具能否撤销以执行结果为准。

详见 [Tools.md §1](Tools.md#1-改动的确认与撤销)。

### 2.3 想把一整轮对话里的改动一起撤回

鼠标移到那条消息上点“回到这里”：这条消息之后还能撤销的改动会依次撤回，会话回到这条消息之前，原文放回输入框。中间夹着你自己手动做的编辑时会拒绝执行，以免撤错东西。

## 3. 会话与面板

### 3.1 切换会话或重启后，输入框里没发的内容还在吗

在。草稿按会话各存一份，输入停顿约 1 秒、或输入框失去焦点时保存。切换会话、在会话窗口之间来回切换、刷新面板（Ctrl+R）、重启编辑器后都会放回来。

### 3.2 回答到一半关了编辑器怎么办

关闭时如果还有回合在进行，会先弹窗确认。确认关闭后，下次打开那个会话，末尾会提示“这一轮没有正常结束”，点“重试”重新发送那条消息。当时排队没发的消息也会保留，但队列是暂停的，点“继续”才会发送，不会自动发出。

### 3.3 会话窗口找不到了

在主页签的会话列表里，带页签图标的那一行就是已经拖成窗口的会话，点它会跳到那个窗口。窗口被关掉的话，会话回到列表里，再拖出来即可。

### 3.4 面板显示不正常

按 Ctrl+R 刷新面板页面。对话、会话、队列和已保存的草稿都不受影响。

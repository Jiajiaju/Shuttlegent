# 批量改属性

## 步骤

1. 确定对象：
   - 用户说“选中的”时用 `get_selection`；
   - 按名称或类型时用 `list_actors` 的 `query`、`class`；
   - 资源用 `find_assets`。
   找不到或数量和用户说的不一致时，先告诉用户再继续。
2. 确定属性：对其中一个对象调用 `get_properties`，按用户说的设置名找到属性（用户说的通常是细节面板上的名字）。属性在组件上时，路径是 Actor 路径加 `.组件名`。有两个以上可能的属性时用 `ask_user` 让用户选。
3. 确定值：按 `get_properties` 显示的格式写新值，例如 `5000`、`true`、`(R=255,G=200,B=150,A=255)`。
4. 写入：
   - 所有对象改成同一个值时，只调用一次 `set_property`，把对象全部放进 `targets`；
   - 按规则逐个算值时（如“都调亮 20%”），先读出每个对象的当前值，相同新值的对象合并成一次调用。
5. 复查：对一个对象再调用一次 `get_properties`，确认新值已生效。
6. 用一张表汇报：对象｜属性｜原值｜新值。

## 注意

- 不保存；用户要求时再用 `save_assets`。
- 位置、旋转、排列用 `arrange_actors`；材质参数和换材质用 material-edit 技能的工具。
- 写入被拒绝或报错时停下来说明原因，不要换其他办法强行改。

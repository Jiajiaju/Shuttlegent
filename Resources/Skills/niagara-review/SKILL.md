# Niagara 检查

引擎的 Niagara 工具在名字含 Niagara 的 Toolset 中；先用 `list_toolsets` 找到它们，再用 `describe_toolset` 查看下面各工具的参数。

## 步骤

1. 确定要查的特效：用户给了路径就用；否则用 `find_assets`（`class` 填 `NiagaraSystem`）按名字或文件夹找。超过 10 个时先问用户只查哪些。
2. 对每个特效依次调用（都是读取，不弹确认卡）：

| 工具 | 看什么 |
|---|---|
| `GetSystemSummary` | 发射器数量与名称、用户变量 |
| `GetSystemCompileState` | 是否编译失败，各脚本的编译错误与警告 |
| `GetStackIssues` | 模块堆栈里的错误、警告、提示（与编辑器堆栈面板中的问题一致），以及每条可用的修复（IssueId、FixId） |

3. 汇总成一张表：特效｜级别（错误 / 警告 / 提示）｜位置（发射器、模块）｜问题｜可否自动修复。按错误、警告、提示排序；每个特效末尾写发射器数量。
4. 有可自动修复的问题时，列出来问用户要修哪几条。用户同意后，逐条用 `ApplyStackIssueFix`（传 IssueId 与 FixId）修复，再调用一次 `GetStackIssues` 确认问题已消失。

## 注意

- 只修复引擎给出的“修复”类条目；“链接”类条目（跳到某处查看）无法自动修复，告诉用户去哪里看。
- 修复会触发特效重新编译，可能要等一会儿；修复工具在后台执行时，以复查结果为准。
- 不要改动用户没提到的模块、发射器或参数，也不要保存；用户要求时再用 `save_assets`。
